# ai-final-project

## Installation
To run the application locally, please first install [Node.js](https://nodejs.org/en/download).

Clone the repository:
``` 
git clone https://github.com/24008338g/ai-final-project.git
```
Alternatively, directly download the `haunted-asylum` folder. 

## Quickstart
To run the application:
```
cd haunted-asylum
npm run dev
```
In your browser, navigate to http://localhost:8080/
